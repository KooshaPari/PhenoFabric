## Scope

R1 turns Phenotype Fabric from a **measurement** layer into a **decision** layer. It does **not** include:

- Wire protocol over real network (PF-WP-040)
- Real-time audio/video transport (PF-WP-050+)
- Multi-tenant fairness leases (PF-WP-022 v2 / R3)
- `fabric-cli` / `fabric-workspace` Rust ports (Tier 3, deferred per ADR-0028)
- `fabric-checker` Rust port (deferred per ADR-0029, Go is canonical)

R1 is the **decision** phase: given capabilities, build a route, fail over when
something dies, surface the user's window/audio cleanly, and prove the
signatures came from a trusted authority.

## Architectural decisions ratified

- **Route-failover is a Rust function returning a typed outcome** (ADR-0030). The Go checker operates at the single-host seam and rejects blacklisted hosts before resource comparison — the operator-facing half of the failover contract. Full topology-driven replan requires cgo / shelling to a Rust binary (R2).
- **Surfaces are leases, not just handles** (spec 019). The `SurfaceHandle` survives re-binds underneath; `SurfaceLease` transitions through `Pending → Active → {Completed, Failed, Revoked, Expired}`. `failover()` is the loud-fail path that flips a lease to `Failed`.
- **Strict-epoch binding is a SurfaceSpec opt-in** (spec 019 §3.1). When on, surfaces are invalidated rather than silently re-bound across topology epochs. Spec 020 enforces this at the `rebind_or_fail` seam.
- **Trust-root is CA-rooted, not direct-key** (ADR-0031). Operators can rotate intermediates without redistributing the root, and can revoke compromised leaves via a signed revocation list from the root. Per-authority `not_after` provides natural key expiry.
- **Go checker is canonical, Rust port is deferred** (ADR-0029). The checker ships as Go (`cmd/checker`); a Rust port is only undertaken if the serde path is needed for workspace event logs (likely R3).
- **Tier 3 Rust crates (`fabric-cli`, `fabric-workspace`, `fabric-checker`) require fresh-context** (ADR-0028). Phase 0 (read all 6+ source files end-to-end before writing) caught three potential cascading-error classes this session — `NodeId::as_str()` doesn't exist, `TopologyEpoch::default()` is not 0, `VerificationKey` doesn't derive Serialize/Deserialize.

## What's intentionally **not** in R1

- **Wire transport** (PF-WP-040) — the protocol for exchanging descriptors between nodes. R2.
- **I/O surface planes** (PF-WP-030) — audio/video/window/device binding. R2.
- **Multi-tenant fairness leases** (PF-WP-022 v2 / R3) — current `leases::rebind_or_fail` is single-tenant.
- **`fabric-cli` Rust** (Tier 3) — requires fresh-context per ADR-0028.
- **`fabric-workspace` Rust** (Tier 3) — requires fresh-context per ADR-0028. The contract is now in place (spec 020) so the workspace can wire `LeaseState::Failed` events without inventing a wire format.
- **`fabric-checker` Rust port** (ADR-0029) — Go is canonical.
- **Full topology-driven replan** in cmd/checker (`-checker-replan -topology <file> -intent <file>`) — requires cgo / shelling to a Rust binary. R2.
- **Deterministic-JSON canonicalization (RFC 8785)** — currently uses serde round-trip. R3 if needed.
- **Link-metrics probe (RTT, bandwidth, loss)** — R3.

## Adoption plan for R1

- **Fabric spec is now self-validating** — any PR that breaks a schema, link, manifest entry, or test fails CI.
- **The Go checker can now reject blacklisted hosts** via `-failover-blacklist id1,id2,...` before resource comparison. Operator workflow: list compromised host IDs in the blacklist, the checker rejects them at decision time.
- **The trust-root model is in place** but not yet wired into the Go checker. A future R2 wedge adds `-trust-root <key-id>:<base64>` and a Go port of `verify_chain` (single-level root verification only) — full chain logic lives in the Rust trust_root module and is callable from any consumer that wants it.
- **`fabric-workspace` (PF-WP-017) now has a documented contract** (spec 020 §3) for wiring `LeaseState::Failed` events into the workspace event log via `RebindOutcome`. The workspace can implement the event log without inventing a wire format.

## Open questions for R2

1. **Where should `-checker-replan` live?** Option A: cgo binding to `fabric-graph` (requires `fabric-capability-ffi` extension). Option B: shelling to a Rust binary (`fabric-checker` reactivated as a Rust port — but that violates ADR-0029 unless workspace needs it). Option C: a thin Rust binary that just calls `replan()` and prints JSON, invoked from `cmd/checker` Go.
2. **Trust-root key pinning in the Go checker**: does the operator pin one root, or a list of roots (rotation)? Spec 021 assumes single-root + revocation; multi-root is R3.
3. **Surface rotation cadence**: how often does `failover::replan` get called — on every topology epoch bump, on every host probe miss, or operator-driven?
4. **Lease FSM recovery**: a `Revoked` lease is terminal. Is there ever a path to re-bind? Spec 019 says no (terminal); spec 020 enforces it.
