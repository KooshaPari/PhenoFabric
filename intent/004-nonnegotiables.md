# Non-Negotiable Intent

1. **Packaged all-in-one experience.** Installation, discovery, graph/workspace control, diagnostics, and APIs must feel like one product.
2. **Modular beneath the shell.** Proven components and platform adapters remain replaceable.
3. **Realtime and scale are co-equal.** A design that is fast only on idle hosts is rejected.
4. **Foreground protection.** Games and Ableton must retain declared latency/frame/audio budgets while agents and builds run.
5. **Full locality ladder.** Same process, same OS, same host/VM, PCIe, LAN, WAN, and OOB each receive purpose-built paths.
6. **Minimum possible stage count.** Every copy, encode, decode, transform, resample, and relay must be justified.
7. **Atomic placement capability.** The architecture must permit finer-than-process placement where implementable.
8. **Adaptive coarsening.** The runtime must fuse fine operations when routing/sharding cost dominates.
9. **Presentation independence.** Applications may visibly live anywhere independent of their execution and data.
10. **Graph-native I/O.** PipeWire/JACK-like nodes, ports, links, timing, and negotiation apply beyond audio.
11. **HDR/color/audio quality.** These are requirements, not later polish.
12. **No fixed host UX.** Any capable device may become the active seat/sink/control surface.
13. **Agent publication without focus theft.**
14. **Clipboard/file/network-drive continuity across Linux/Wayland/X11, Windows, and macOS.**
15. **Relative input correctness for games/CAD and ordinary cursor-edge behavior for desktop work.**
16. **Safe fallback and OOB access for bench machines.**
17. **Ecosystem boundaries remain explicit.**
18. **Claims require evidence under concurrent load.**
