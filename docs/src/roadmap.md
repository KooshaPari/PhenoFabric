# Product and Research Roadmap

## Horizon 1 — Measured local fabric

- main PC/VM capability graph;
- central input broker and focus transactions;
- Looking Glass/KVMFR orchestration with SPICE recovery;
- local audio/file/clipboard graph;
- graph/workspace UI and desk/couch templates;
- stage-level evidence lab.

**Proof:** one keyboard/mouse/audio/display workflow across host and disjoint VMs with no stuck state and no unnecessary encoded same-host path.

## Horizon 2 — Cross-device creator/gaming fabric

- Windows/macOS agents;
- M1 Pro as third display and couch seat;
- direct wired LAN media;
- HDR/color and workload-specific quality policy;
- protected Ableton and game resource islands;
- OOB integration for bench machines.

**Proof:** foreground game/Ableton remains inside declared SLO under agent/compiler/game-E2E pressure.

## Horizon 3 — Agent and explicit compute fabric

- ephemeral realm/provider API;
- surface/terminal/report publication;
- versioned object authority/residency;
- explicit TaskSpec/RegionSpec placement;
- ShareCLI/NVMS/thegent adapters;
- placement explanation and counterfactual evidence.

**Proof:** real workloads use more suitable available hardware when total cost justifies it and decline movement when data/state cost wins.

## Horizon 4 — Seamless surfaces and WAN

- RAIL/FreeRDP, Xpra and Waypipe adapters;
- native pixel-proxy fallback and owned-window graph;
- independent audio/input/video/bulk WAN channels;
- roaming/direct/relay path changes;
- recovery and update hardening.

**Proof:** supported Windows/Linux apps visibly live beside native apps, with deterministic fallback and no focus theft.

## Horizon 5 — Adaptive and atomic research

- region formation from traces;
- fusion/fission, prediction and bounded speculation;
- FUSE/syscall/function/kernel interposition experiments;
- GPU external-memory/P2P, RDMA/NIXL and future CXL tiers;
- selective checkpoint/migration/rematerialization.

**Proof:** each promoted mechanism beats explicit/static baselines after movement, synchronization, failure and foreground externality are counted.
