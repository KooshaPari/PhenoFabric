# Build Order Rationale

1. **Measure before optimizing.** Capability and stage timing must precede route/scheduler claims.
2. **Ship local utility first.** Same-host VM input/display/audio and workspace focus produce immediate value.
3. **Add cross-device endpoints.** MacBook display/seat validates packaged continuity.
4. **Protect foreground work.** Ableton and games expose scheduler/media failures that idle demos hide.
5. **Publish agent surfaces.** Ephemeral realms connect the product to actual agent workflows.
6. **Add explicit compute/data placement.** Cooperative TaskSpec/object references provide a correct baseline.
7. **Add seamless app windows.** High UX value, but platform edge cases are large.
8. **Add adaptive/atomic research.** Only after a measured baseline can net benefit be proven.
9. **Harden WAN/OOB and packaging throughout.** Recovery and updates are architecture, not post-launch chores.
