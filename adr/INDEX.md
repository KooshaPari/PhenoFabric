# Architecture Decision Record Index

Format follows the existing ecosystem ADR convention: status/date/deciders/supersedes/traceability, followed by context, decision, alternatives, consequences, and references.

| ADR | Decision | Status |
|---|---|---|
| [0001 — Define Phenotype Fabric As The Execution/Data/I O Substrate](0001-fabric-product-boundary.md) | Phenotype Fabric owns physical resource discovery, placement, data residency, transport compilation, interactive I/O, surfaces, and RT QoS. It does not own product intent, labor delegation, economic allocation, traceability, or durable session history. | Accepted |
| [0002 — One Packaged Product Shell Over Modular Adapters](0002-one-shell-modular-runtime.md) | Ship one installer/application identity, workspace model, UI, CLI, and API. Implement capabilities through replaceable platform and transport adapters with independent health and versioning. | Accepted |
| [0003 — Use A Pipewire/Jack Inspired Typed Node Port Link Graph](0003-universal-typed-graph.md) | Represent devices, realms, processes, surfaces, resources, transforms, and endpoints as nodes with typed ports. Links express intent; compiled routes express implementation. | Accepted |
| [0004 — Search Locality Tiers Before Remote Transports](0004-locality-first-route-selection.md) | The route compiler searches L0 same-process through L8 OOB in order of physical cost, prunes by constraints, then scores valid candidates. Tier order is a heuristic, not an absolute rule. | Accepted |
| [0005 — Permit Atomic Placement But Execute Fused Regions By Default](0005-atomic-capability-adaptive-regions.md) | Support the finest safe interceptable granule—task, function, syscall, I/O operation, or accelerator kernel—but dynamically fuse neighboring decisions into execution regions when overhead or shared state dominates. Split regions when a distinct optimum emerges. | Accepted |
| [0006 — Keep Compute, Data, I/O, Resource, And Product Graphs As Projections](0006-multi-projection-shared-identity.md) | Use shared canonical IDs but maintain distinct graph projections and engines: compute, data, I/O, resource, product, work, evidence, and economic. Cross-links are references, not shared ownership. | Accepted |
| [0007 — Do Not Introduce A Universal Database Or Ontology](0007-no-universal-database.md) | Share IDs, envelopes, and schemas. Each product retains independent storage and authoritative state. Materialized views may be built from events. | Accepted |
| [0008 — Protect Local Real Time Islands Before Distributing Critical Loops](0008-protected-realtime-islands.md) | Define RT0/RT1 protected islands and admit them before throughput work. Keep tightly coupled live audio/game loops local unless measured end-to-end budgets prove a remote route. | Accepted |
| [0009 — Prefer Shared Memory And Device Dma Before Compression](0009-shared-memory-before-codecs.md) | For eligible same-OS and same-host paths, use direct references, SHM, DMA-BUF, IVSHMEM/KVMFR, virtio/vhost, or device handles before codec stages. Codec paths are fallback when isolation/format/distance requires them. | Accepted |
| [0010 — Prefer Semantic Application Remoting Before Pixel Proxies](0010-semantic-before-pixel.md) | Use RAIL/RemoteApp, Xpra, Waypipe, Qubes/WSLg-like semantic paths where available. Use a native pixel proxy as a universal fallback, then whole desktop when proxy semantics fail. | Accepted |
| [0011 — Use A Mobility Hierarchy Instead Of One Process Migration Claim](0011-mobility-hierarchy.md) | Define M0 surface projection, M1 semantic handoff, M2 application checkpoint, M3 process checkpoint, M4 VM migration, and M5 workload rematerialization. Choose the least invasive mechanism satisfying intent. | Accepted |
| [0012 — Use Leases And Fencing Tokens For Exclusive Focus And Routes](0012-exclusive-route-leases.md) | Exclusive resources use one authoritative lease service and monotonically increasing fencing tokens. Endpoints reject stale tokens. Focus transfer releases held controls before commit. | Accepted |
| [0013 — Treat Input, Audio, Video, And Device Clocks Independently](0013-independent-media-clocks.md) | Each stream has its own timing contract and clock domain. Synchronization intent may connect them, but buffering, recovery, and transport remain independent. Network audio uses timestamping, drift estimation, bounded elasticity, and ASRC where needed. | Accepted |
| [0014 — Make Color And Hdr Intent Authoritative Graph Metadata](0014-color-hdr-first-class.md) | Ports advertise bit depth, primaries, transfer, luminance, ICC/EDID, HDR and refresh capabilities. Routes record preservation or explicit transform. Desktop text, gaming, color-critical, and video profiles differ. | Accepted |
| [0015 — Keep Sharecli Standalone And Integrate It As A Privileged Runtime Client](0015-sharecli-boundary.md) | Do not absorb ShareCLI. Define adapters through which it supplies process/resource signals and executes delegated local actions. The fabric owns cross-device placement and interactive I/O; ShareCLI owns its standalone local runtime/supervisor contract. | Accepted |
| [0016 — Preserve Agslag, Agileplus, Thegent, Tracera, And Ledger Authority](0016-ecosystem-authority.md) | AGSLAG decides resource worth; AgilePlus owns governed commitments; thegent owns labor dispatch; Fabric owns physical execution/data/I-O; Tracera owns evidence links; SessionLedger owns operational history. Exchange IDs/events only. | Accepted |
| [0017 — Agents May Publish And Request Attention But Not Steal Focus](0017-agent-non-stealing.md) | Agents receive capability-scoped publication and attention APIs. Human focus takeover requires explicit policy/action. Surface origin, owner, purpose, TTL, and resource budget remain visible. | Accepted |
| [0018 — Maintain An Independent Out Of Band Recovery Plane](0018-oob-independent-recovery.md) | Important physical machines expose KVM-over-IP or physical-switch recovery on a restricted management network. OOB is a separate capability and never treated as the preferred high-performance path. | Accepted |
| [0019 — Use Mutual Identity And Narrow Privileged Helpers](0019-mutual-pairing-privileged-isolation.md) | Pair through ephemeral key agreement and out-of-band confirmation. Store device keys in platform secret stores. Split privileged helpers by device class and use capability-bound, versioned protocols. | Accepted |
| [0020 — Use Phenotype Fabric As A Working Name Only](0020-provisional-name.md) | Use `Phenotype Fabric` / `phenotype-fabric` in this package. Treat it as provisional and avoid irreversible namespace or legal claims until product-boundary validation. | Accepted |
| [0021 — Prefer Immutable Objects And Explicit Mutable Authority](0021-object-authority-immutability.md) | Runtime objects are immutable/content-addressed by default. Mutable objects declare one authority or a named consistency protocol. Replicas/caches never become authoritative implicitly. | Accepted |
| [0022 — Keep Coordinator Off Payload And Rt Hot Paths](0022-control-data-plane-separation.md) | The coordinator manages identity, desired state, plans, leases, and evidence references. Endpoint peers execute data planes directly or through blind relays. RT engines operate compiled local schedules. | Accepted |
| [0023 — Signed Capability Descriptor Schema and FFI](0023-capability-inventory-schema.md) | CapabilityDescriptor uses Ed25519 signatures, blake3 canonical-bytes for identity, a hand-authored C ABI, and JSON Schema validation. Canonical-bytes strips signatures before hashing. | Accepted |
| [0024 — NVMS Adapter — Mapping `odin.nvms` to Fabric CapabilityDescriptor](0024-nvms-adapter.md) | `crates/phenotype-nvms-adapter` translates odin.nvms v0.2 YAML manifests into Fabric `CapabilityDescriptor` instances. Required/bounds model separates minimum viable from acceptable range. | Accepted |
| [0025 — Route Plan Semantic Model](0025-route-lease-semantic-model.md) | RoutePlan and SeatLease model captures compile decisions, locality tier enforcement, negotiation score, RT island protection, preferred-node hints, and multi-step sequences. Lease semantics use monotonic fencing tokens. | Accepted |
